# README Guide to setup the frontend

## Step 1. While at the root directory initialise the frontend using NextJS

```bash
npx create-next-app@16.3.7 frontend --typescript --tailwind --eslint --app --src-dir --use-npm
```

OR for latest version

```bash
npx create-next-app@latest frontend --typescript --tailwind --eslint --app --src-dir --use-npm
```

## Step 2. Install the required node modules

```bash
npm i
```

OR

```bash
npm install lucide-react clsx tailwind-merge class-variance-authority framer-motion axios zod react-hook-form @hookform/resolvers @supabase/supabase-js
```
